# Team

This project is built by:

* Ata
* ChatGPT
* Cursor

# Roles

## Ata

* owns the business decisions
* reviews implementation
* learns the system deeply

## ChatGPT

Used for:

* architecture
* planning
* debugging help
* breaking work into tickets
* reviewing decisions

## Cursor

Used for:

* implementing tickets
* editing files
* refactoring safely
* wiring features together

# Communication Style

Keep responses:

* short
* clear
* practical

Avoid:

* verbose explanations
* corporate wording
* fake senior-engineer language
* repeating points
* AI-sounding writing

# Working Rules

Do not assume unclear requirements.

If something is vague:

* ask questions
* explain assumptions
* propose options

Do not invent architecture that was not discussed.

# Implementation Rules

Prefer:

* small commits
* isolated changes
* simple solutions
* readable code
* small files

Avoid:

* giant rewrites
* unnecessary abstractions
* touching unrelated systems
* overengineering

# Debugging

When debugging:

* investigate before patching
* explain root cause
* include full errors
* include reproduction steps

# Main Rule

Do not optimise for looking advanced.

Optimise for:

* clarity
* maintainability
* reliable progress
* business value
